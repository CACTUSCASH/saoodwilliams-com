HONEST LIMITS

          
Small language.
Real bytes.

        

        
    
          
  • 
            Values are i32, i64, f64 and bool. There are no strings, arrays,
            structs or globals; raw bytes in one 64 KiB page of linear memory
            are reachable through the load and store intrinsics.
          
    • 
          
  • 
            Parsing stops at the first syntax error. Type errors are collected
            and reported together with their line, column and a fix hint.
          
    • 
          
  • 
            There is no optimiser. The emitter is a direct translation of the
            typed tree, so modules are larger than a production compiler would
            produce.
          
    • 
          
  • 
            Programs run in a Web Worker behind a 4 second watchdog with 64 KB
            of console output. Float to int casts saturate instead of trapping;
            integer division by zero traps.
