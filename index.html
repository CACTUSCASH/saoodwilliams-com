Full-stack product

Freelance Ledger

An invoicing and income tracker for freelancers who bill clients abroad. Add clients, raise invoices with line items, mark them paid, and see what is outstanding and what you have earned, per currency. Email sign-in, a Postgres schema where row level security scopes every row to its owner, money stored in integer minor units, and a tested library for the totals. It has unit tests and a GitHub Actions pipeline that runs the type check, tests, a production build and a Docker image build on every push. Multi-currency totals are converted through a live exchange-rate API, and it ships with a multi-stage Docker build and Docker Compose.

How I build

AI-assisted engineering, and tooling for it

I work AI-assisted, with Claude Code and the Model Context Protocol, and it is a large part of how I ship real software quickly on my own. I treat the model as tooling: I make the architectural calls, review every line, and can walk through anything I have shipped. The speed comes from removing the busywork, not from handing over the thinking.

I also build for that ecosystem rather than only using it. mcp-headers and mcp-sqlite are MCP servers I wrote so an assistant can do real work through a clean, bounded interface: one grades a site's security headers, the other gives read-only database access with writes fenced off. claude-mcp-profiler came from wanting to see which tool calls were slow. Building the tools taught me where the sharp edges are, which makes me better at using them.

The rest of my workflow is ordinary and deliberate: typed code, tests around the logic that matters, continuous integration, and small honest commits.
