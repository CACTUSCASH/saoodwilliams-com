01

headerscan

A security-header scanner for any website.

Paste a URL and it pulls the response headers, grades them A to F against the OWASP baseline, and gives you the exact header to add for each gap. The grading engine is pure functions with unit tests behind it, so the score is something you can check rather than something you take on faith.

Next.js 15 · TypeScript · Vitest

02

mcp-headers

The same scan, turned into a tool Claude can call.

An MCP server built on the official SDK that exposes one job: scan a site's security headers and grade them. I wrote it to find out how clean the Model Context Protocol could make the line between a model and real work, and the answer was pretty clean.

TypeScript · MCP SDK · Zod

03

mcp-sqlite

Read-only database access for a model, with the writes fenced off.

An MCP server that lets Claude list tables, read schema and run SELECT queries against SQLite, while writes are blocked at the connection and behind an allow-list. It runs on Node's built-in SQLite, so there are no native build steps waiting to break on someone else's machine.

TypeScript · MCP SDK · node:sqlite

A WebGL hero section you can drop into a Next.js app.

Glass material, real bloom, and motion that stays smooth on an actual iPhone, which is the part most WebGL demos quietly skip. Built with React Three Fiber and GLSL I wrote by hand instead of pasting.

05

shader-play

Fifty thousand particles, all moving on the GPU.

Every particle's motion is computed in a shader, so the CPU does nothing per frame and the whole field holds full frame rate while you drag the sliders. It started as a way to actually understand GLSL rather than copy it, and it turned into the thing I reach for when I want to test an idea.

TypeScript · WebGL · GLSL

nextjs-ios-scroll-perf

A write-up of why a real site stuttered on iPhones.

Three separate bugs on the Cipher30 site, each with the fix: a scroll library fighting the browser, a carousel handler firing on every scroll event, and a clock that re-rendered the whole page once a second. I like this one because nothing here is a demo. It was a real thing that was broken, and now it isn't.
