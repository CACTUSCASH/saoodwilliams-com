# saoodwilliams.com

My personal site and portfolio. Next.js 15, TypeScript, React Three Fiber,
Tailwind CSS, deployed on Vercel.

- `/` — hero + selected work + about + contact
- `/blog` — technical war stories and notes

## Dev

```bash
npm install
npm run dev
```

## Deploy

Push to GitHub, connect the repo to Vercel, deploy. That's the whole flow.
